ルート: 設定タブ (`/#/tournaments/:id/settings`・HashRouter) — 大会情報の編集・試合結果の削除・大会の削除を行う画面。

実装: `src/features/tournament/settings/index.tsx`（`SettingsTab`）、`src/features/tournament/settings/schema.ts`

## 画面構成

「設定」見出し（`h2`）と「編集」ボタン（右上）を表示する。

### 大会情報の表示

編集モードでないときは以下の項目を定義リスト（`dl`）で表示する:

| 項目   | 内容                   |
| ------ | ---------------------- |
| 大会名 | 大会名の文字列         |
| 形式   | シングルス / ダブルス  |
| 開催日 | 開催日（整形表示）     |
| 参加者 | 参加者数（`N 人`）     |
| 試合   | 登録試合数（`N 試合`） |

### 大会情報の編集

「編集」ボタンを押すと編集モードに切り替わり、フォームが表示される。

- **大会名**: テキスト入力（最大20文字、必須）。バリデーションエラー時は赤字でメッセージ表示。
- **開催日**: date入力（必須）。バリデーションエラー時は赤字でメッセージ表示。
- 「キャンセル」ボタン: 編集を破棄して表示モードに戻る。
- 「保存」ボタン: バリデーションが通ったときのみ活性（`isValid` が true）。押すと `updateTournament` を呼び出して変更を保存し、表示モードに戻る。

バリデーション（`src/features/tournament/settings/schema.ts`）:

- 大会名: 空文字不可（`"大会名を入力してください"`）、20文字超不可（`"大会名は20文字以内で入力してください"`）
- 開催日: 未選択不可（`"開催日を選択してください"`）

変更できる項目は **大会名と開催日のみ**（形式・ゲーム数は変更不可）。

## 試合結果を削除

ボタンラベル: **「試合結果を削除」**（`variant="dangerOutline"`）

説明文: 「大会・参加者は残し、試合の記録だけを削除します。」

押すと確認ダイアログを表示する:

| ダイアログ項目 | 内容                                                   |
| -------------- | ------------------------------------------------------ |
| タイトル       | 試合結果を削除                                         |
| メッセージ     | この大会の試合記録を全て削除します。参加者は残ります。 |
| 確認ボタン     | 削除する（`destructive`）                              |
| キャンセル     | やめる                                                 |

確認後の動作（`resetTournament`）:

- 大会に紐づく全試合（`tournamentId` が一致する全 `Match`）をストアから削除する。
- 大会・参加者はそのまま残る。

---

## 大会を削除

ボタンラベル: **「大会を削除」**（`variant="danger"`）

説明文: 「大会・参加者・試合を全て削除します。」

押すと確認ダイアログを表示する:

| ダイアログ項目 | 内容                                                 |
| -------------- | ---------------------------------------------------- |
| タイトル       | 大会を削除                                           |
| メッセージ     | 大会・参加者・試合を全て削除します。取り消せません。 |
| 確認ボタン     | 削除する（`destructive`）                            |
| キャンセル     | やめる                                               |

確認後の動作（`deleteTournament`）:

- 大会に紐づく全試合・全参加者・大会自体をストアから削除する。
- ホーム画面（`/`）へ遷移する。

---

## ストア操作

| 操作           | スライス          | 関数               | 変更範囲                               |
| -------------- | ----------------- | ------------------ | -------------------------------------- |
| 大会情報の保存 | `tournamentSlice` | `updateTournament` | `name`・`date` を部分更新              |
| 試合結果を削除 | `tournamentSlice` | `resetTournament`  | `tournamentId` 一致の全 `Match` を削除 |
| 大会を削除     | `tournamentSlice` | `deleteTournament` | 大会・参加者・試合を全削除             |
