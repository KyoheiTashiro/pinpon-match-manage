ルート: `/#/`（HashRouter） — 大会一覧の表示と新規大会の作成を行うトップ画面。

## 画面構成

### ヘッダー

- アプリ名「卓ログ」を表示。
- 右側に歯車アイコンの「設定」ボタンを配置。タップすると `SettingsModal` を開く。
  - `SettingsModal` 内に文字サイズ切替（`FontSizeControl`）を配置。
    - 選択肢: 極小 / 小 / 標準 / 大 / 特大（セグメント型コントロール）。
    - 選択値は `fontSize` ストアに保存される。

### メインエリア

大会作成フォーム（表示中）またはフォームを開くボタン、大会一覧、フッターボタン群を縦に並べる。

---

## 機能

### 新規大会作成

ボタン「＋ 新しい大会」を押すとインラインフォームに切替わる。

#### フォーム項目

| 項目     | UI                                             | デフォルト   |
| -------- | ---------------------------------------------- | ------------ |
| 大会名   | テキスト入力（プレースホルダ: `例: 春の大会`） | 空           |
| 形式     | ラジオカード: `シングルス` / `ダブルス`        | `シングルス` |
| ゲーム数 | ラジオカード: `3` / `5` / `7`                  | `5`          |
| 開催日   | date ピッカー（カレンダーアイコン付き）        | 当日の日付   |

#### バリデーション（`schema.ts` zod 定義）

| フィールド | ルール                                | エラーメッセージ                                                                 |
| ---------- | ------------------------------------- | -------------------------------------------------------------------------------- |
| 大会名     | 必須・20文字以内（trim後）            | 空: 「大会名を入力してください」、超過: 「大会名は20文字以内で入力してください」 |
| 形式       | `singles` または `doubles` のいずれか | —                                                                                |
| ゲーム数   | `3` / `5` / `7` のいずれか            | —                                                                                |
| 開催日     | 必須（1文字以上）                     | 「開催日を選択してください」                                                     |

- 「作る」ボタンはフォーム全体が valid になるまで disabled。
- 「キャンセル」を押すとフォームをリセットして閉じる。

#### 作成後の挙動

大会が作成されると `/tournaments/:id/participants` へ自動遷移する（`navigate` で push）。

---

### 大会一覧

- `tournaments` ストアの全大会を一覧表示。
- 大会が0件の場合は「まだ大会がありません。上のボタンから作成してください。」を表示。
- 各行に大会名と開催日（`YYYY年M月D日` 形式・JST）を表示し、行全体がボタンになっており押すと `/tournaments/:id/participants` へ遷移する。
- 参加者数は表示しない。

#### ソート仕様

開催日の降順 → 同日は `createdAt` 降順。

```ts
const list = Object.values(tournaments).sort(
  (a, b) => (b.date ?? "").localeCompare(a.date ?? "") || b.createdAt.localeCompare(a.createdAt),
);
```

### ホーム画面に追加（PWA インストール）

「ホーム画面に追加」ボタン（`InstallAppButton`）をフッターに表示する。

- すでにスタンドアロンモード（インストール済み）の場合はボタンを非表示。
- `beforeinstallprompt` イベントを受け取った場合: ボタン押下でシステムのインストールプロンプトを表示。ユーザーが受諾すると非表示。
- `beforeinstallprompt` 非対応ブラウザ（iOS Safari / Android Firefox 等）の場合: ボタン押下で手動インストール手順ガイドダイアログを表示。
  - iOS: Safari の共有ボタン → 「ホーム画面に追加」手順。
  - その他: ブラウザメニュー → 「アプリをインストール」手順。

### 全データ削除

`SettingsModal` 内のデータ管理セクションに「データ初期化」ボタン（`variant="danger"`）を配置する。

- ボタンを押すとモーダル内インラインの確認UI（ダイアログではなく `border-danger` の枠内）に切り替わる。
- 確認UI本文: 「全ての大会・参加者・対戦結果を削除します。取り消せません。本当に削除しますか?」
- 確認ボタン: 「全て消す」（`variant="danger"`）
- キャンセルボタン: 「やめる」（`variant="secondary"`）
- 確認を押すと `resetAll` アクションが呼ばれ全ストアが初期化され、モーダルが閉じる。
