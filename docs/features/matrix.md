ルート: 対戦表タブ (`/#/t/:id`) + 試合詳細モーダル + スコアボード（ポータル） — 総当たり組合せの表示・試合詳細入力・スコアボードを統合する画面群。

## マトリクス表示

- 縦軸・横軸に参加者名（ダブルスはペア名）
- セル内容:
  - 未対戦: 空
  - 対戦済: ゲームスコア（例 `3-1`）+ クリックで詳細
  - 自セル: 黒塗り
- 対称セル（B vs A）には逆スコアを自動反映

### 視認性

- セル内スコア 24〜32px
- 勝者側に薄い緑背景 + 太枠、敗者側に薄い赤背景
- 自セル（黒塗り）は斜線パターン併用（色のみに頼らない）
- スマホ縦持ち時は 横スクロール + **1列目（自分の行名）固定**
- 行・列ホバー/タップで該当行・列をハイライト（読み迷い防止）

**ワイヤー（シングルス例・大型セル）:**

```
┌──────────────────────────────────┐
│ ← もどる   春季リーグ            │
│ [参加者][対戦表][順位][設定]     │ ← タブ大型
├──────────────────────────────────┤
│        田中    佐藤    鈴木      │
│ 田中  ████   ３−１   −        │
│        ████  (勝)              │
│ 佐藤  １−３   ████   ２−３     │
│       (負)   ████   (負)       │
│ 鈴木   −    ３−２   ████       │
│              (勝)   ████       │
└──────────────────────────────────┘
```

セルは64px以上・勝者セル淡緑+太枠・敗者セル淡赤・自セル斜線。タップで試合詳細。

## 組合せ生成

- 参加者確定後 シングルスはマトリクス表セルから対戦追加、ダブルスは試合フォームから追加
- シングルス: 同組合せは1試合のみ（重複追加時 既存試合を返す）
- ダブルス: 対戦時に左右ペア（各2名）を選択。事前のペア固定なし
  - ダブルスは試合数が爆発するため ユーザー手動追加方式
- 組合せはマトリクス表のセルとして表示

## 試合詳細モーダル

1試合あたりの記録項目:

| 項目 | 型 | 必須 |
|------|-----|------|
| 対戦者 (左/右) | participantId or pairIds[2] | 必須 |
| ゲーム1〜5 点数 | { left: int, right: int } × 最大5 | 1ゲーム以上 |
| メモ | string | 任意 |

ゲーム勝敗判定: 11点先取・2点差デュース。`>=11 かつ 差>=2`で勝者確定。  
試合勝敗判定: 3ゲーム先取で確定（最大5ゲーム）。3-0/3-1/3-2のみ有効。

入力UI: ゲームごとに点数2フィールド。3ゲーム先取になった時点で残ゲーム入力ロック。

モーダル内の点数加減UI（ゲーム1, ゲーム2...の±ボタン）は**スコアボード画面**（下記）に切り出す。モーダルからは「スコアボードを開く」ボタンで遷移。モーダル右上の閉じる操作は**×ボタンではなく「青背景の保存ボタン」**で行う（タップで保存 → モーダル閉じる）。

関連ロジック: [data-model.md#ロジック仕様](../architecture/data-model.md#ロジック仕様)（ゲーム勝敗、試合勝敗）

**ワイヤー:**

```
┌──────────────────────────────────┐
│ 試合の入力      [ 保存 ]         │ ← 右上 青背景 保存ボタン (×ボタン廃止)
│                                  │
│   田中    対    佐藤             │ ← 28px
│                                  │
│ 終了:  [ 14:25 ]                 │
│                                  │
│ ┃ ゲーム1 ┃ 11 - 5  (勝)         │ ← 表示のみ
│ ┃ ゲーム2 ┃ 11 - 8              │
│ ┃ ゲーム3 ┃ 9 - 11               │
│ ┃ ゲーム4 ┃ 11 - 6               │
│ ┃ ゲーム5 ┃ 終了 ／ 入力不可     │
│                                  │
│ 田中の勝ち  3 - 1                │ ← 32px太字 緑
│                                  │
│ [ ▶ スコアボードを開く ]         │ ← 大型 点数入力は別画面
│                                  │
│ [ 保存 ]               [ 削除 ]  │ ← 保存: 青  削除: 赤
└──────────────────────────────────┘
```

点数加減±UIは本モーダルから削除し、スコアボード画面（下記）に移動。モーダルでは各ゲームのスコア結果のみ表示。

## スコアボード

試合進行中、選手・観客から視認しやすい大型スコア表示専用画面。`createPortal` で `document.body` 直下に描画するフルスクリーンモーダル（独立ルートなし）。

- 起動: 試合詳細モーダル内の「スコアボードを開く」ボタン
- 戻る: 画面左上「← もどる」ボタンで試合詳細モーダルへ復帰（`onBack` prop）
- 表示要素:
  - 参加者の名前（左/右）
  - 現在のゲームの点数（大型表示）
    - 操作: スコア領域の上半分タップで +1、下半分タップで −1。0〜30 にクランプ
  - 全体のゲーム取得数（中央列、例: `2 - 1`）
  - ゲーム切替ボタン群（G1〜G5）。完了済ゲームは緑枠、ロック済かつ未入力はグレー
  - 左右入替ボタン（⇄ 入替）— 左右の表示・操作対象を反転
  - サーブ権インジケーター（各サイド下部のオレンジバー）— `matchFirstServer` 指定時のみ表示
  - マッチポイント表示（該当サイドのスコアを黄色 `text-yellow-400`）
  - 入力ロック表示（`lockedFromIndex` 以降のゲーム選択時）
  - もどるボタン
- 配色: **青背景 `bg-blue-800` ・白文字**。勝利側（現在ゲーム勝者・試合勝者）は**緑 `text-success`**で強調
- 向き: **スマホサイズ時は横向き（landscape）前提**のレイアウト
  - CSS Media `(orientation: portrait) and (max-width: 900px)` 時は「端末を横向きにしてください（画面の回転ロックがオンの場合は、解除してください）」誘導バー表示
  - 横向き時: 左右に選手スコア、中央に全体ゲーム数・ゲーム番号・入替ボタンを配置
- ダイアログ:
  - **ゲーム終了**: 現在ゲーム決着 かつ 次ゲーム進行可能時 → `ConfirmDialog`「次のゲームへ / キャンセル」。一度dismissしたゲームは再表示しない（`dismissedRef`）
  - **試合終了**: 試合勝者確定時 → `ConfirmDialog`「試合一覧へ戻る (`onBack`) / 閉じる」。最終ゲーム勝数を表示（例: `3 - 1`）。一度dismissで再表示しない
- 入力はLocalStorageへ即時反映（モーダル復帰時に同期不要）

**ワイヤー（横向き前提）:**

```
┌──────────────────────────────────────────────────────┐
│ ← もどる    [G1][G2][G3][G4][G5]                     │ ← 白文字 ゲーム切替
│──────────────────────────────────────────────────────│
│                                                      │ 青背景
│   田中           ゲーム 2          佐藤              │
│                  2 - 1                                │ ← 全体ゲーム数
│  (緑:勝利側)    [⇄ 入替]                              │
│                                                      │
│  ┌─────┐                          ┌─────┐           │
│  │ tap+│ ← 上半分タップで+1        │ tap+│           │
│  │     │                          │     │           │
│  │ 11  │                          │  5  │           │ ← 巨大数字
│  │     │                          │     │           │   (黄=マッチP)
│  │ tap-│ ← 下半分タップで-1        │ tap-│           │
│  └─────┘                          └─────┘           │
│  ▬▬▬▬▬ ← サーブ権 (オレンジ)                          │
└──────────────────────────────────────────────────────┘
```

- 背景: `bg-blue-800` / 文字: `#FFFFFF` / 勝利強調: 緑 `text-success` / マッチポイント: 黄 `text-yellow-400` / サーブ権: オレンジ `bg-orange-500`
- スマホ縦持ち時 (`portrait and max-width: 900px`): 黄色バーで「端末を横向きにしてください」案内
- スコア部は上下半分タップで +1/−1 (0〜30 にクランプ)
- ゲーム決着・試合決着で `ConfirmDialog` 自動表示（次ゲーム遷移 / 試合一覧へ戻る）
- 戻るボタンで試合詳細モーダルへ復帰（モーダルは裏で開いたまま）
