ルート: 結果タブ (`/#/t/:id`) — 大会参加者の勝敗集計・順位・対戦結果を表示する画面。

## 画面構成（表示モード切替）

「結果」見出しの直下・画面上部に **サブタブ2つ** を置き、表示モードを切り替える:

| サブタブ                 | 内容                                                                     |
| ------------------------ | ------------------------------------------------------------------------ |
| **点数表**（デフォルト） | 順位表 + 対戦結果テーブル（従来どおり）                                  |
| **グラフ**               | 全試合の点数進行グラフを一覧表示（[result-graph.md](./result-graph.md)） |

- 切替はタブ内ローカル状態（URL・LocalStorage に保持しない）。
- グラフモードでは **全試合を一覧**で表示する。`pointLog` を持たない試合も
  行（対戦者名見出し）は出し、「得点記録なし」と表示する。
- **画像保存**: 「結果の画像を保存」ボタンは両モード共通。**表示中のモードの内容**を
  `useImageCapture('結果')` で画像化する。サブタブUI自体は画像に含めない
  （大会名・日付ヘッダは両モードとも画像に含める）。

## 順位表

ソート基準（上から順に適用）:

1. 勝数（多い順）
2. ゲーム得失差（取ゲーム − 失ゲーム）
3. 点得失差（取点 − 失点）

表示列: 順位・名前・試合数・勝・敗・ゲーム得失・点得失

## 順位算出

各参加者ごとに集計:

```
wins, losses
gamesWon, gamesLost → gameDiff = won - lost
pointsFor, pointsAgainst → pointDiff = for - against
```

ソート: `[-wins, -gameDiff, -pointDiff, name]`

ダブルスはメンバー個人単位で集計（メンバー2人それぞれに勝敗加算）。
